# Python Fundamentals

Coursework and practice exercises completed during the freeCodeCamp *Scientific
Computing with Python* certification — Phase 0 of a structured machine learning
roadmap.

These are learning exercises rather than portfolio projects. End-to-end ML work
lives in a separate `ml-portfolio` repository.

## Contents

| # | Exercise | Concepts practised |
|---|---|---|
| 01 | [User Configuration Manager](./01-user-config-manager) | Dictionaries, tuples, string formatting, function design |
| 02 | [Email Simulator](./02-email-simulator) | Classes, composition, dunder methods, type hints |

## Running

```bash
python 01-user-config-manager/config_manager.py
python 02-email-simulator/email_simulator.py
```

Requires Python 3.9+. No external dependencies.
